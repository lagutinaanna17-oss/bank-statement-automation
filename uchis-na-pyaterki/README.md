# Учись на пятёрки — сайт для своего домена

Школа с 1 по 11 класс: темы по программе, ИИ-учитель, абакус, логика, счёт, дневник.
Здесь лежит версия для собственного сайта с аккаунтами и оплатой.

## Что внутри

| Папка | Что это |
|---|---|
| `web/page.html` | Сама страница школы (та же, что опубликована в Claude) |
| `web/adapter.js` | Подключает страницу к серверу сайта вместо Claude |
| `server/app.py` | Сервер: вход, подписка, оплата ЮKassa, выдача уроков, чат с учителем |
| `server/generate_lessons.py` | Заготавливает уроки по темам и кладёт их в базу |
| `server/curriculum.json` | Список предметов и тем по классам |
| `legal/` | Черновики оферты и политики персональных данных |
| `deploy/` | Готовые настройки для сервера |

## Как это работает

- **Бесплатно без входа:** первая тема каждого предмета, абакус, логика, счёт.
- **По подписке:** остальные темы и ИИ-учитель. 49 ₽ за 30 дней для 1–4 классов, 100 ₽ для 5–11. Цены меняются в настройках.
- **Уроки готовятся заранее.** Команда `generate_lessons.py` один раз составляет уроки через Claude и сохраняет их. Ученики получают готовые уроки, поэтому расход на ИИ не растёт с числом учеников.
- **Живой ИИ — только чат с учителем**, с дневным лимитом вопросов на аккаунт.
- **Подписка не продлевается сама:** родитель каждый раз платит кнопкой.

Абакус, логика и счёт работают прямо в браузере, поэтому закрыть их за оплату нельзя — сервер защищает только уроки и учителя.

## Что не проверено

Проверено на тестовом запуске: пробный урок, регистрация, вход, отказ без подписки, оплата в тестовом режиме, уроки и учитель после оплаты, перенос результатов на другое устройство, обработка уведомлений об оплате.

**Не проверено с настоящими сервисами** — ключей у автора кода не было:
- реальный платёж через ЮKassa (в том числе как она выдаёт чеки для самозанятого);
- реальные запросы к Claude: чат с учителем и заготовка уроков;
- доступность API Anthropic с российского сервера.

Проверьте это на тестовом магазине ЮKassa и на одном предмете, прежде чем звать учеников.

## Запуск на своём компьютере для пробы

```bash
cd server
python3 -m venv ../venv && ../venv/bin/pip install -r requirements.txt
DEV_MODE=1 FAKE_AI=1 ../venv/bin/uvicorn app:app --port 8000
```

Откройте http://127.0.0.1:8000. В этом режиме оплата засчитывается без денег, а учитель отвечает заготовкой.
Уроков в базе ещё нет, темы покажут «урок готовится».

## Запуск на сервере

Нужен сервер с Ubuntu (VPS) и купленный домен, направленный на адрес сервера записью типа A.

1. Скопируйте папку проекта в `/opt/uchis` и установите зависимости:
   ```bash
   sudo apt install -y python3-venv caddy
   sudo useradd --system --home /opt/uchis uchis
   sudo mkdir -p /var/lib/uchis && sudo chown uchis /var/lib/uchis
   sudo python3 -m venv /opt/uchis/venv && sudo /opt/uchis/venv/bin/pip install -r /opt/uchis/server/requirements.txt
   ```
2. Скопируйте `.env.example` в `/etc/uchis.env`, впишите адрес сайта и ключи, закройте файл: `sudo chmod 600 /etc/uchis.env`.
3. Скопируйте `deploy/uchis.service` в `/etc/systemd/system/` и запустите:
   ```bash
   sudo systemctl enable --now uchis
   ```
4. Скопируйте `deploy/Caddyfile` в `/etc/caddy/Caddyfile`, замените `ваш-домен.ru` на свой домен и выполните `sudo systemctl reload caddy`. HTTPS включится сам.
5. Заполните `legal/oferta.md` и `legal/privacy.md` (они открываются по адресам `/oferta` и `/privacy`) и перезапустите: `sudo systemctl restart uchis`.

## ЮKassa

1. Зарегистрируйтесь в ЮKassa как самозанятый и создайте магазин для своего сайта. Для подключения ЮKassa попросит оферту и контакты на сайте.
2. В личном кабинете возьмите идентификатор магазина и секретный ключ, впишите в `/etc/uchis.env`.
3. В настройках магазина включите HTTP-уведомления о событии `payment.succeeded` на адрес `https://ваш-домен.ru/api/yookassa/webhook`.
4. Сначала проверьте всё на тестовом магазине ЮKassa.

Сервер не верит уведомлению на слово: он переспрашивает у ЮKassa статус и сумму платежа и только тогда открывает доступ.

## Заготовка уроков

```bash
cd /opt/uchis/server
sudo -u uchis env $(sudo cat /etc/uchis.env | grep -v '^#' | xargs) ../venv/bin/python generate_lessons.py --grades 1-4 --dry-run
```

Команда с `--dry-run` только считает, сколько уроков нужно составить. Без него — составляет и в конце печатает расход токенов.
Начните с одного предмета одного класса (`--grades 3 --subjects math`), посмотрите расход и качество, потом запускайте остальное.
Прерванный запуск можно повторить: готовые уроки пропускаются.

Всего тем: 855 (с учётом двух учебников математики в 1–4 классах). При двух вариантах на тему это 1710 уроков.
Уроки составляет ИИ — выборочно перечитывайте их перед запуском: в базе они лежат в таблице `lessons`.
