# COOLiNAUTO — сайт-лендинг

Статический лендинг: `index.html`, `styles.css`, `script.js`, `policy.html`.
Все контактные данные, цены и ссылки собраны в объекте `CONFIG` в начале
`script.js` — редактировать нужно только там.

## Чек-лист перед публикацией

1. **Логотип и палитра.** Логотип не был предоставлен. Сейчас используется
   временная палитра (графитово-синий + белый + охра) в `styles.css`
   (переменные `--color-primary`, `--color-accent`). Когда появится файл
   логотипа — обновить переменные под его реальные цвета и добавить сам
   логотип (сейчас в шапке/подвале текстовый логотип).
2. **Фото.** Все изображения — плейсхолдеры (`images/placeholder.svg`).
   Нужно заменить на реальные фото: цех, руководитель Антон Кулин, команда,
   до/после ремонта. Рекомендуется формат WebP + `loading="lazy"` (уже
   выставлено на всех `<img>`).
3. **Кейсы.** Раздел «Примеры работ» — 3 карточки-заглушки с пометкой
   «Демо — заменить на реальные». Заполнить реальными кейсами (модель
   коробки, проблема, что сделали, срок, стоимость).
4. **Отзывы.** 3 карточки-заглушки. Заменить на реальные отзывы или убрать
   заглушки, оставив только ссылки на Яндекс Карты / YouTube.
5. **FAQ.** Список вопросов основан на фактах из брифа. При появлении новых
   вопросов от владельца — дополнить `#faq-accordion` в `index.html`.
6. **Цены и гарантия.** Актуальны на момент разработки (см. `CONFIG.services`
   и `CONFIG.warranty` в `script.js`). Перед публикацией — свериться с
   владельцем, не изменились ли они.
7. **Яндекс.Метрика.** Место под код счётчика помечено комментарием
   `<!-- Яндекс.Метрика: вставить код -->` перед закрывающим `</body>` в
   `index.html`.
8. **submitLead().** В `script.js` функция `submitLead(data)` сейчас только
   логирует данные в консоль (`console.log`) и показывает экран «Спасибо».
   Нужно подключить реальную отправку (email / CRM / Telegram-бот) — см.
   `// TODO: подключить email/CRM/Telegram`.
9. **Домен и OG-изображение.** В `index.html` прописан временный домен
   `https://coolinauto.ru/` в `canonical`, Open Graph и Schema.org — заменить
   на реальный домен и загрузить `images/og-cover.jpg` (1200×630).
10. **Юридические реквизиты.** Проверить `policy.html` — реквизиты ИП взяты
    из брифа (ИНН 325305948671, ОГРНИП 317325600022990).

## Как залить на хостинг

Сайт полностью статический (HTML/CSS/JS без сборки) — подходит для любого
статического хостинга:

- **Через FTP/SFTP на обычный хостинг:** загрузить содержимое папки
  `coolinauto/` целиком в корень домена (или в нужную поддиректорию).
- **Через панель хостинга (например, timeweb, reg.ru, beget):** загрузить
  файлы в `public_html/` через файловый менеджер.
- **Через Netlify/Vercel/GitHub Pages:** подключить репозиторий и указать
  папку `coolinauto/` как корень публикации (build command не нужен —
  сайт статический).

После заливки:
1. Проверить, что домен указывает на `index.html`.
2. Вставить код Яндекс.Метрики (см. пункт 7 чек-листа).
3. Проверить формы (honeypot, чекбокс согласия, отправку `submitLead`).
4. Проверить переключатель городов и кнопки «Показать номер» на мобильном
   и десктопе.
